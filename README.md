# OXAI 2026 forwarding page

This repository serves https://threadslab.org/oxai2026/ and forwards visitors to https://oxai2026.github.io/.

The full workshop website is maintained in https://github.com/oxai2026/oxai2026.github.io.

JavaScript preserves query strings and section anchors. A meta refresh and visible link provide fallbacks. GitHub Pages serves this as an HTML redirect, not a server-side HTTP 301. The THREAD Lab homepage is unaffected.

Do not replace this forwarding page with a duplicate workshop site.
